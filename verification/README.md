# Verification records

The manuscript's 2026 historical verification reports, reviewer responses, citations and raw-performance discussion in this directory are **archival research evidence**. The exact earlier executable research artifact and raw samples are accessible from the [pre-Rust snapshot](https://github.com/imxade/DOC/tree/snapshot-2026-11-17-pre-rust-runtime) and **not** part of `master`'s active runtime.

Only the mathematically independent finite DOC checkers kept here remain available as bounded exploratory evidence. They are not DOC language runtimes, do not establish Rust/Goose compilation, and must never be reported as tests of either executable. Historical scripts requiring CMake, archived benchmark CSVs or CI have been removed from this development branch.

The active truth about Rust/Goose implementation status lives in [MODEL-REQUIREMENT-TRACE.md](../MODEL-REQUIREMENT-TRACE.md), [CLAIM-EVIDENCE-MAP.md](../CLAIM-EVIDENCE-MAP.md), [issue #7](https://github.com/imxade/DOC/issues/7) and [issue #9](https://github.com/imxade/DOC/issues/9). No GitHub Actions are used.
