- Native causal recurrence (`native repeat`) drives real input-dependent effect epochs with explicit typed carries and a derived terminal condition. `native_stream.doc` transfers a variable-sized stream over a fixed authorized byte region and selects the exact read/write lengths; the fixture has no transfer loop. Independent tests verify scoped destructor execution per epoch, checked failure and bounded nontermination without result publication. This addresses repeated effects without an application-specific C driver.
- Region extent and `native_arena.doc` show checked offset/alignment/extent arithmetic and native memory use over caller-authorized storage. Allocation policy is DOC-authored; low-level OS region provision and the valid backing-storage contract are external platform services. Do not confuse this privileged offset allocator with ordinary DOC-managed lifetimes or claim a finished production reclamation algorithm.
